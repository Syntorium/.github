# .github

This is the special [`.github`](https://docs.github.com/en/organizations/collaborating-with-groups-in-organizations/customizing-your-organizations-profile) repository for the [@syntorium](https://github.com/syntorium) organization.

It hosts community health files and the public-facing organization profile rendered on [github.com/syntorium](https://github.com/syntorium).

## Contents

| Path | Purpose |
|---|---|
| [`profile/README.md`](profile/README.md) | Org profile shown on the public organization page |

## Notes

- The repository **must remain public** for the profile to render.
- Files added at the root (e.g. `CODE_OF_CONDUCT.md`, `CONTRIBUTING.md`, `SECURITY.md`, `SUPPORT.md`, `ISSUE_TEMPLATE/`, `PULL_REQUEST_TEMPLATE.md`, `FUNDING.yml`) become **organization-wide defaults** for any Syntorium repo that doesn't define its own.
- Edits to `profile/README.md` go live on the org page as soon as they're pushed to the default branch.
